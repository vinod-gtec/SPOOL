# Put your music here

Drop your audio files (`.mp3`, `.m4a`, `.aac`, `.ogg`, `.wav`, `.flac`, `.opus`) directly into this
folder, commit, and push. SPOOL reads this folder straight from GitHub every time the site loads, so
there's no rebuild step — add a file, push, tap **Re-sync** in the app.

Tip: files are listed in the app in filename order (numbers sort naturally), so prefix them if you
want a specific order, e.g.:

```
music/
  01 - Intro.mp3
  02 - Song Title.mp3
  03 - Another One.mp3
```

Underscores and dashes in filenames are turned into spaces for display, so `Late_Night_Drive.mp3`
shows up as "Late Night Drive".
